# Electronics Store Invoice Generator

A Python desktop application built with `Tkinter` and `ReportLab` to quickly generate and export PDF receipts for electronics market transactions.

## Features

- **Customer Data Capture**: Store customer name and phone details.
- **Dynamic Product Entry**: Add multiple electronics items with quantity and price validation.
- **Live Total Aggregation**: Automatic item total and grand total calculation.
- **PDF Export**: Generates styled, print-ready PDF invoices.

## Prerequisites

- Python 3.8 or higher
- `reportlab` library
